# Screenshots

All taken in a headless browser at 400 x 800 with `node scripts/screenshots.mjs <prefix> --script scripts/shots/<file>.mjs`.

| Prefix | What |
| --- | --- |
| `s1-` | Stage 1, the map (start, whole map, reef, rocks, red lighthouse fort, ocean) |
| `s2-` | Stage 2, the idle loop (running, collecting, upgrade sheet, beach facilities) |
| `s3-` | Stage 3, wave surfing levels 2 to 4 (locked cards, unlocked zones) |
| `s4-` | Stage 4, unlocks and skimboarding (locked sport card, cove, rocks) |
| `s5-` | Stage 5, the Sea area (haze clearing, three sports side by side, kite launch area) |
| `s6-` | Stage 6, the Ocean area (sailing card, ocean, jetty with boats, whole map) |
| `polish-` | Stage 7, polish (sports panel, confetti, beach decoration and buildings) |
| `lm-` | Landmarks close up (reef, Nazaré, rocks) |
| `size-` | Layout at other screen sizes (small phone, iPhone, tablet, desktop) |
| `dpr2-` | Start screen on a 2x screen |
| `e2e-` | A real play session through the interface (buy, hire, welcome back popup) |
| `final-` | The last set, in order 01 to 14, from a fresh start to a fully unlocked game |
